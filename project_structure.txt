Project summary:
- FastAPI application for AI-powered IT support
- Multi-agent system for security, ticket analysis, retrieval, and recommendation
- Hybrid search using BM25 + embeddings
- SQLite database for users, tickets, knowledge articles, and logs
- Role-based access for customer, support, analyst, and admin
- Evaluation scripts for IR performance metrics
